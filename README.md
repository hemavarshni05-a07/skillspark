## Important
This starter uses browser localStorage, so it is a functional prototype for testing on one browser/device. It is NOT yet a public multi-user production system.

For the real public version:
Website → secure backend → database → authentication → staff roles → AI API.
Never put an AI API key inside frontend JavaScript.
